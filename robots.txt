# ⚠️⚠️ AND A ROBOTS BLOCK IS NOT THE SAME AS A NOINDEX TAG, SO THE TWO ARE USED IN DIFFERENT PLACES:
#   - To keep a PAGE out of Google, the page carries <meta name="robots" content="noindex">. That works
#     because the crawler is ALLOWED to fetch it and can therefore read the tag.
#   - To keep a FOLDER out, this file is used — but it only stops CRAWLING. A URL can still be listed if
#     something links to it, which is why nothing in the shop links to /test/.
#   ⚠️ Never both on the same thing: a crawler refused the page can never read its noindex tag.
